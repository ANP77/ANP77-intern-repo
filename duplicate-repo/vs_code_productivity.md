# VS Code shortcuts 

## Shortcuts that I find useful
### Navigation
| Action | Shortcut | Description |
| ------ | -------- | ----------- |
| Quick File Open | Cmd + P | Search and open files by name |
| Open Command Palette | Cmd + Shift + P | Access any VS Code command or setting | 
| Toggle Sidebar | Cmd + B | Show or hide the sidebar |
| Open New Window | Cmd + Shift + N | Launch a new VS Code instance | 
| Close Window | Cmd + Shift + W | Close the current VS Code window | 

### Editing
| Action | Shortcut | Description |
| ------ | -------- | ----------- |
| Comment Line | Cmd + / | Toggle line comment for the selected line(s) |
| Select Next Occurrence | Cmd + D |Select the next matching occurrence, allowing multiple selections to be edited simultaneously | 
| Save File | Cmd + S | Save the current file | 
| Find in File | Cmd + F | Search within the current file |

### Debugging
| Action | Shortcut | Description |
| ------ | -------- | ----------- |
| Start Debugging | F5 | Begin or continue debugging |
| Toggle Breakpoint | F9 | Add or remove a breakpoint on the current line |
| Stop Debugging | Shift + F5 | End the debugging session | 

### Terminal Commands
| Action | Shortcut | Description |
| ------ | -------- | ----------- |
| Toggle Terminal | Ctrl + ` | Show or hide the integrated terminal |
| New Terminal | Ctrl + Shift + ` | Create a new terminal instance |

## Shortcuts That I Think Will Be the Most Useful in My Daily Work
I think Cmd + P, Cmd + /, Cmd + S, Cmd + F, Cmd + D, and Ctrl + Shift + ` will be the most useful in my daily work.

When working on projects with multiple files, Cmd + P will help me navigate between files more efficiently. Cmd + / will make it easier to quickly comment or uncomment sections of code without manually adding or removing comment symbols. This will be especially useful when debugging, as I can quickly disable and re-enable certain sections of code to help identify issues. Cmd + S will allow me to quickly save my changes. Cmd + F will help me find specific content without having to go through the entire file, while Cmd + D will allow me to select and edit multiple occurrences of the same text simultaneously. Finally, Ctrl + Shift + ` will allow me to quickly open a new terminal to run commands.

## How Can Keyboard Shortcuts Improve My Productivity?
Keyboard shortcuts can make coding faster and more efficient by simplifying repetitive tasks and reducing the need to navigate through menus. They can save time when searching for files, editing code, and running commands. For example, instead of reading through a file line by line to find something, I can use Cmd + F to quickly locate specific content. Using shortcuts regularly will help me stay focused on coding and improve my overall workflow.
