# Setting up a React project Reflection 

## What challenges did you face during setup?
The setup process was relatively straightforward as I followed the official Tailwind CSS documentation. However, I was initially hesitant to modify the configuration and CSS files automatically generated by Vite, as I was concerned that making incorrect changes might affect the project. Following the documentation helped me understand which files needed to be modified and how Tailwind CSS integrates with React. This task helped me become more confident in setting up and configuring a React development environment.

Resource: https://tailwindcss.com/docs/installation/using-vite
