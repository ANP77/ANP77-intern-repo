# AI Tools Reflection

## Which AI tools did you try?
I have used GitHub Copilot, ChatGPT and Claude AI during my university projects and personal development work to help with coding, debugging and understanding unfamiliar concepts.

## What worked well? What didn’t?
GitHub Copilot, ChatGPT, and Claude AI are all quite good at generating code snippets. I particularly like using ChatGPT for debugging because it provides detailed explanations, and I use it regularly in my day-to-day development work. I also prefer ChatGPT when learning new concepts or trying to understand how something works, as I can ask follow-up questions until I fully understand the explanation. I also like using GitHub Copilot to identify errors and get code suggestions directly within VS Code, which makes debugging more convenient.  I have recently started using Claude AI more frequently. Although I have not used it as much as the other two tools, I am currently exploring its features and getting more familiar with it.

One limitation I have noticed with AI tools in general is that their suggestions are not always accurate. Sometimes, the generated code includes unnecessary parts or approaches that are more complicated than needed. Therefore, I think it is important to review, understand, and test AI-generated code rather than relying on it completely.

## When do you think AI is most useful for coding?
I think AI is most useful for providing a good starting point, identifying errors quickly, exploring different approaches, and learning new concepts. It can save a lot of time. I also find it particularly helpful for understanding not just how a solution works, but why it works and what alternative methods could be used. This allows me to learn more effectively and improve my own coding skills.
