# Git Basics Reflection

## Have you used Git before? 
Yes, I have used Git in my university projects to manage code changes and collaborate with team members. I am familiar with several Git commands and mainly use basic commands such as git add, git commit, git push, and git pull in my day-to-day work. Although I have experience using Git, I would still like to explore more of its features and become more confident with advanced commands.

## Which Git client (if any) did you choose? Why?
I have mostly used Git in VS Code. I first started using it because it was required for my very first university project. Since I have become familiar and comfortable with it, I have continued using it ever since. I find it very convenient, and I also like being able to customise the interface with different themes, which makes the experience more enjoyable.

## What was the most interesting thing you learned about Git today?
While completing this issue, I came across a LinkedIn post titled "Fun Git & GitHub Facts You (Probably) Didn’t Know!" One interesting fact I learned was that Git was created following a disagreement over the use of an existing version control system and that Linus Torvalds developed its initial version in just 10 days. I had always assumed Git was planned and developed over a longer period of time, so I found it fascinating that such a widely used tool had such an interesting origin.
