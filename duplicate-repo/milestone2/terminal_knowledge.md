# Terminal Knowledge Reflection

## Which terminal client did you choose? Why?
I chose to use the integrated terminal in VS Code with zsh as my shell. I have been using it since my university projects, mainly to navigate between directories, install dependencies, and run commands. Since I am already familiar and comfortable with it, I decided to continue using it. I also find it very convenient.

## What customizations (if any) did you make?
I haven't made any specific customisations to the terminal itself yet, as I am comfortable with the current setup.

## What was the most useful command you learned today?
I learned about several useful commands while researching terminal basics, but one of the most useful commands I have learned and used is ls, which lists the files and directories in the current location. I use this command quite frequently, especially when I am unsure about which files or folders are present in a directory. It helps me navigate through projects and confirm that I am working in the correct location before running other commands. Although it is a simple command, I find it very helpful in my day-to-day development work.
